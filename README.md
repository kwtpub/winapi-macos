# winapi-macos 0.3.0

Библиотека для запуска учебных C++-программ с графикой через `windows.h`
на macOS. Работает на Apple Silicon и Intel. Поддерживаемый код менять
не нужно: графика открывается в отдельном окне, а `cout` остаётся в терминале.

## Установка

Нужны Homebrew и инструменты C++ из Xcode или Command Line Tools.
Если инструменты ещё не установлены, выполните `xcode-select --install`.

```sh
brew install kwtpub/tap/winapi-macos
winapi-macos --setup
```

`--setup` один раз настраивает команды компилятора в терминале (zsh или bash).
После этого **откройте новую вкладку Terminal**.

## Сборка и запуск

В новой вкладке перейдите в папку с исходниками вашей программы и выполните:

```sh
winapi-macos
g++ *.cpp -o app
./app
```

Первая команда добавляет в проект папку `mac-native` с библиотекой.
Выполните её для каждой новой практики. Исходники проекта не изменяются.
Заголовки и библиотеки при сборке подключаются автоматически.

После изменения кода снова выполните `g++ *.cpp -o app`, затем `./app`.
Если в папке несколько программ со своим `main()`, укажите файлы одной из них:

```sh
g++ main.cpp Point.cpp -o app
```

Для управления клавишами сначала нажмите на графическое окно.

## Что поддерживается

Точки, контуры эллипсов, сплошные перья, цвета, опрос клавиатуры и задержки:
`SetPixel`, `Ellipse`, `CreatePen`, `RGB`, `GetAsyncKeyState`, `Sleep`
и связанные функции. Совместимость ограничена этим набором учебной графики.

## Отмена настройки терминала

```sh
winapi-macos --unsetup
```

Откройте новую вкладку Terminal. Папки `mac-native` в проектах сохранятся.
