# winapi-macos

Переносная прослойка для учебных C++-программ, которые рисуют через
`windows.h`, `GetWindowDC`, `SetPixel`, `CreatePen` и `Ellipse`.
На macOS рисунок появляется в нативном окне Cocoa, вывод `cout` —
в терминале. Учебные исходники менять не нужно.

## Установка и запуск

```sh
brew install kwtpub/tap/winapi-macos
```

Перейдите в папку практики с исходниками и выполните:

```sh
winapi-macos --run
```

Команда добавит `mac-native/`, соберёт программу и запустит её.
Установщик поддерживает Apple Silicon и Intel; для сборки учебных
программ нужны Apple Clang и SDK из Xcode или Command Line Tools:

```sh
xcode-select --install
```

Для установки без запуска используйте `winapi-macos`, для выбора
назначения — `winapi-macos --dir "/путь/к/практике"`.
Установщик не изменяет `.cpp` и `.pro`. Повторная установка одинаковых
файлов безопасна; изменённые файлы комплекта заменяются только с `--force`.

После установки:

```sh
./mac-native/run.sh
./mac-native/build.sh
```

Первая команда собирает и запускает проект, вторая только собирает.
По умолчанию выбираются все `.cpp`, `.cc`, `.cxx` и `.C` в корне проекта.
Если там несколько `main()` или исходники лежат в подпапках,
перечислите файлы одной программы:

```sh
./mac-native/run.sh src/main.cpp src/Point.cpp
```

Готовая программа сохраняется в `mac-native/<имя-папки>_native`.
Для qmake добавьте после настроек `CONFIG`:

```qmake
include($$PWD/mac-native/mac-native.pri)
```

## Возможности и ограничения

Поддерживаются контекст одного окна, RGB-точки, сплошные перья, контуры
эллипсов, опрос клавиатуры активного окна и `Sleep` с обработкой событий.
Координаты начинаются сверху слева; рисунок сохраняется при перерисовке.
Qt и Wine для запуска через скрипты не требуются.

Это подмножество WinAPI для учебной графики. Кисти, заливка эллипсов,
пунктирные перья, глобальный опрос клавиатуры и произвольные Win32-окна
не реализованы. Код с другими вызовами Windows API или собственными
зависимостями может потребовать дополнительных изменений.
Вызовы прослойки должны выполняться в главном потоке.

Фон по умолчанию синий `RGB(0,0,255)`; цвет стирания фигур должен совпадать
с фоном. Например, для белого фона:

```sh
env GDI_BACKGROUND=255,255,255 ./mac-native/run.sh
```

Подробные настройки, клавиши, отладка и проверки описаны
в [документации модуля](mac-native/README.md).

## Исходники, сборка и проверки

- [Заголовок совместимости](mac-native/windows.h) — поддерживаемые типы,
  константы и функции.
- [Реализация Cocoa](mac-native/gdi_compat.mm) — окно, рисунок и клавиатура.
- [Установщик](mac-native/tools/installer.cpp) и
  [сборщик пакета](mac-native/tools/package.py) — автономный комплект.
- [Проверки переносимости](mac-native/tools/check_portability.py) и
  [графические проверки](mac-native/tests/smoke.mm).

Из корня репозитория на macOS:

```sh
python3 mac-native/tools/package.py
python3 mac-native/tools/check_portability.py --no-gui
```

Python 3 и Apple Clang нужны только для сборки установщика из исходников.
В `mac-native/dist/` появятся `winapi-macos`, `mac-native.zip`,
`winapi-macos-0.1.0-universal-macos.tar.gz` и `SHA256SUMS`.

CI проверяет синтаксис, universal-сборку и переносимость без графической
сессии. Проверки Cocoa можно включить отдельным параметром `gui_smoke`
при ручном запуске CI; им нужна доступная графическая сессия macOS.

Текущая версия — **0.1.0**. Готовые файлы доступны
в [релизах](https://github.com/kwtpub/winapi-macos/releases).
